# Terminal Practice

Use this folder for small shell and text-file experiments.

## Files

- `args.sh`: shortest possible script for checking command-line arguments.
- `demo.sh`: fuller argument-loop example.
- `file1.txt`: tiny text file for `cat`, `grep`, `wc`, `head`, and `tail`.
- `notes.txt`: tiny note file for editing and copying practice.

## Next Commands To Practice

```bash
pwd
ls
cat file1.txt
grep hello file1.txt
wc -l file1.txt
bash args.sh apple
bash demo.sh apple banana cherry
```
