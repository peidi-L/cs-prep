# UCL MSc Computer Science Prep Plan

Starting point: MSc Computer Science at UCL, September 2026.

Official UCL areas to prepare for:
- Introductory Programming
- App Engineering
- Computer Architecture and Operating Systems
- Algorithmics
- Database Fundamentals
- MSc Computer Science Project
- Optional areas such as Functional Programming, Interaction Design, Software Engineering, Entrepreneurship, and Machine Learning

## Main Goal

Arrive at UCL able to:
- Write clean Python confidently.
- Understand algorithms and data structures well enough to solve unseen problems.
- Use Git, terminal, VS Code/Cursor, and debugging without panic.
- Build a small full-stack web app.
- Understand basic databases, SQL, operating systems, and computer architecture.
- Start thinking early about project/dissertation ideas.

## Phase 1: Foundations

Duration: 6-8 weeks

Focus:
- Python basics: variables, loops, functions, classes, files, exceptions.
- Problem solving: lists, dictionaries, sets, recursion.
- Terminal basics: folders, paths, commands, running programs.
- Git and GitHub: commit, branch, pull, push, merge.

Practice:
- 5 coding problems per week.
- 1 small script per week, such as a file organiser, expense tracker, flashcard quiz, or PDF renamer.

Target outcome:
- You can solve easy coding problems without looking up every step.
- You can create a GitHub repo and push your code.

## Phase 2: Algorithms and Data Structures

Duration: 8-10 weeks

Focus:
- Big-O notation.
- Arrays/lists, stacks, queues, hash maps, sets.
- Linked lists, trees, graphs.
- Sorting and searching.
- Recursion and dynamic programming basics.

Practice:
- 4-6 LeetCode easy/medium problems per week.
- Keep a notes file with patterns, not just answers.

Target outcome:
- You can explain why one solution is faster than another.
- You recognise common algorithm patterns.

## Phase 3: Databases and App Engineering

Duration: 8-10 weeks

Focus:
- SQL: SELECT, JOIN, GROUP BY, indexes, constraints.
- Database design: tables, relationships, normalisation.
- Web basics: HTTP, APIs, JSON.
- Backend: Python Flask or FastAPI.
- Frontend basics: HTML, CSS, JavaScript or React.

Project:
- Build one full-stack app, such as:
  - job application tracker
  - habit tracker
  - study planner
  - book/course notes app

Target outcome:
- You can design a database and connect it to an app.
- You understand how a browser, server, and database work together.

## Phase 4: Systems

Duration: 6-8 weeks

Focus:
- Binary, memory, CPU basics.
- Processes and threads.
- Filesystems.
- Operating system responsibilities.
- Networking basics.
- C basics if time allows.

Practice:
- Write short notes explaining each topic in your own words.
- Use small experiments: inspect files, run processes, use command-line tools.

Target outcome:
- Architecture and OS lectures feel familiar, not alien.

## Phase 5: Project and Career Direction

Duration: ongoing from spring/summer 2026

Explore 2-3 possible directions:
- Software engineering
- Machine learning / AI systems
- Human-computer interaction
- Data engineering
- FinTech
- Research / PhD pathway

Portfolio targets:
- 2 polished GitHub projects.
- 1 clean CV.
- 1 LinkedIn/GitHub profile.
- 1 short personal website or portfolio page.

## Weekly Routine

Minimum effective week:
- 3 coding sessions, 60-90 minutes each.
- 1 algorithms session.
- 1 project-building session.
- 1 review session: write notes, clean code, push to GitHub.

Better week:
- 5 coding sessions.
- 2 algorithms sessions.
- 2 project sessions.
- 1 reading/notes session.

## First 14 Days

Day 1:
- Set up GitHub.
- Make a folder for coding practice.
- Create first repo.

Day 2:
- Python variables, lists, dictionaries.
- Solve 2 easy problems.

Day 3:
- Functions and files.
- Write a script that renames or organises files.

Day 4:
- Git basics.
- Commit and push your script.

Day 5:
- Loops, conditionals, error handling.
- Solve 2 easy problems.

Day 6:
- Classes and simple objects.
- Build a small command-line to-do list.

Day 7:
- Review and tidy code.

Day 8:
- Big-O basics.
- Arrays/lists problems.

Day 9:
- Hash maps/dictionaries.
- Solve 2 problems.

Day 10:
- SQL basics.
- Create a tiny database table.

Day 11:
- HTML/CSS basics.
- Make one simple webpage.

Day 12:
- Flask or FastAPI hello-world app.

Day 13:
- Connect a small app idea to a file or database.

Day 14:
- Write a reflection: what was easy, what was confusing, what to repeat.

## What To Avoid

- Do not spend months only watching tutorials.
- Do not try to learn every programming language.
- Do not wait until you feel ready before building projects.
- Do not ignore maths and algorithms.
- Do not keep code only on your laptop; push to GitHub.

## Success Check Before September 2026

You are ready if you can:
- Build a small app from scratch.
- Use Git without fear.
- Solve common easy algorithm problems and some medium ones.
- Write SQL queries with joins.
- Explain basic OS concepts.
- Read documentation without getting lost.
- Talk clearly about one project you built.
