# CS Prep

This repo is your working space for learning computer science before the UCL MSc.

## What Is Here

- `Plan.md`: the full 8-week prep plan and internship roadmap.
- `python-practice/`: Python examples and small exercises.
- `terminal-practice/`: shell scripts and tiny files for command-line practice.

## What To Do Next

1. Finish `python-practice/beginner_exercises.py` without looking at the answers.
2. Run `python-practice/fizz_buzz.py` from the terminal with different limits.
3. Read and run sections of `python-practice/example_codes.py`.
4. Add tests for `fizz_buzz.py`.
5. Start a `data-structures/` folder with stacks, queues, hash maps, and linked lists.
6. Start a `sql-practice/` folder and work through basic `SELECT`, `WHERE`, `JOIN`, and `GROUP BY`.
7. Begin the main maths learning project once Python basics feel comfortable.

## Weekly Habit

Every study session should end with:

```text
what I practiced:
what confused me:
what I will do next:
```

Then commit the useful change.
